# SWYNEX – Exploratory Data Analysis

## Project Overview
This project focuses on cleaning and analyzing sales data using Microsoft Excel. It includes data quality checks, sales summaries, and dashboard visualizations.

## Objectives
- Clean and organize sales data.
- Identify missing values and duplicate records.
- Check sales data for inconsistencies.
- Analyze sales by city, product, category, payment method, and month.
- Present findings through summaries and an Excel dashboard.

## Tools Used
- Microsoft Excel
- Data Cleaning
- Exploratory Data Analysis (EDA)
- Data Visualization

## Project Deliverables
- Raw sales data
- Cleaned sales data
- Data quality checks
- Sales summary reports
- Dashboard and charts

## Skills Practiced

- Sales analysis
- Summary reporting
